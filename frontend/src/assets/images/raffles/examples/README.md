# Imágenes de Ejemplo para Rifas

Esta carpeta contiene imágenes de ejemplo para mostrar rifas en la aplicación.

## Estructura recomendada:

### Nombres de archivos:
- `raffle-car-01.jpg` - Rifa de automóvil
- `raffle-phone-01.jpg` - Rifa de teléfono
- `raffle-house-01.jpg` - Rifa de casa
- `raffle-electronics-01.jpg` - Rifa de electrónicos
- `raffle-cash-01.jpg` - Rifa de dinero en efectivo

### Especificaciones técnicas:
- **Formato:** JPG, PNG, WebP
- **Tamaño recomendado:** 800x600px (4:3) o 1200x800px
- **Peso máximo:** 500KB por imagen
- **Calidad:** Alta resolución para mostrar detalles del premio

### Categorías sugeridas:
- **Automóviles:** Carros, motos, bicicletas
- **Electrónicos:** Teléfonos, laptops, televisores
- **Inmuebles:** Casas, apartamentos, terrenos
- **Dinero:** Premios en efectivo
- **Misceláneos:** Electrodomésticos, joyas, etc.

## Uso en la aplicación:

```typescript
// Ejemplo de cómo referenciar las imágenes
const raffleCar = 'assets/images/raffles/examples/raffle-car-01.jpg';
const rafflePhone = 'assets/images/raffles/examples/raffle-phone-01.jpg';
```

```html
<!-- En templates HTML -->
<img src="assets/images/raffles/examples/raffle-car-01.jpg" alt="Rifa de Automóvil">
```
